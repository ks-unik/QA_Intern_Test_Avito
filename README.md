## ⚙️ Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/ks-unik/QA_Intern_Test_Avito.git
cd QA_Intern_Test_Avito-1
```

### 2. Создание и активация виртуального окружения (опционально)

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

---

## ▶️ Запуск автотестов

```bash
pytest -sv --alluredir=allure-results
```

---

## 📊 Просмотр Allure-отчёта

```bash
allure serve allure-results
```

После выполнения команды откроется браузер с интерактивным отчётом.

## ✅ Что проверяют автотесты

* создание объявления (POST);
* получение объявления по id (GET);
* получение объявлений по sellerId (GET);
* удаление объявления (DELETE);
* получение статистики (2 эндпоинта);
* валидация структуры и типов данных ответа;
* проверка бизнес-ограничений (диапазоны, неотрицательные значения, обязательные поля).

* наличие обязательных полей
