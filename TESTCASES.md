# TEST CASES – API Ads Microservice

## TC-01: Create ad

**Тип:** Позитивный
**Метод:** POST
**Endpoint:** /api/1/item
**Описание:** Создание нового объявления.
**Шаги:**

1. Отправить POST-запрос с данными объявления.
2. Проверить статус код 200.
3. Получить UUID из ответа POST.
4. Отправить GET-запрос `/api/1/item/{uuid}` для получения тела созданного объявления.
5. Валидировать ответ GET через модель `AdModel`.
   **Ожидаемый результат:** Объявление создаётся успешно, GET-запрос возвращает корректное тело объявления, данные соответствуют модели, UUID совпадает с созданным.
