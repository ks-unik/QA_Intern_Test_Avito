Тест-кейсы для микросервиса объявлений (16 тест-кейсов, 10 автотестов)
1. Создание объявления (POST /ads)
Позитивные сценарии

ATC-001
Категория: Создание объявления
Подтип: Позитивный
Название: Создание объявления с валидными данными
Эндпоинт: /ads
Метод: POST
Покрытие: Валидные обязательные поля
Ожидаемый результат: 200 OK
Комментарий: Параметризованный автотест, покрывает несколько кейсов с валидными данными
Автотест: test_create_ad_valid_data

ATC-002
Категория: Создание объявления
Подтип: Негативный

Комментарий: Параметризованный автотест, покрывает несколько негативных кейсов
Автотест: test_create_ad_invalid_data

ATC-003
Категория: Создание объявления
Подтип: Негативный
Название: Создание объявления с уже существующим id
