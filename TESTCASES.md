# Тест-кейсы для микросервиса объявлений

**Общее количество тест-кейсов:** 16  
**Количество автотестов:** 9  

---

## 1. Создание объявления
**Endpoint:** `POST /ads`

### 1.1 Позитивные сценарии

**ATC-001 — Создание объявления с корректными данными**
- **Тип:** Позитивный  
- **Покрытие:** все обязательные поля заполнены валидными значениями  
- **Ожидаемый результат:** `200 OK`, объявление успешно создано  
- **Комментарий:** параметризованный автотест, проверяет несколько вариантов валидных данных  
- **Автотест:** `test_create_ad_valid_data`

---

### 1.2 Негативные сценарии

**ATC-002 — Создание объявления с невалидными значениями полей**
- **Тип:** Негативный  
- **Покрытие:**  
  - пустой `title`  
  - `title` меньше или больше допустимой длины  
  - отсутствуют обязательные поля (`sellerID`, `price`)  
- **Ожидаемый результат:** `400 Bad Request`  
- **Комментарий:** параметризованный автотест  
- **Автотест:** `test_create_ad_invalid_data`

**ATC-003 — Проверка уникальности id**
- **Тип:** Позитивный  
- **Покрытие:** несколько POST-запросов создают уникальные объявления  
- **Ожидаемый результат:** каждый POST возвращает новый уникальный `id`  
- **Комментарий:** отдельный автотест, проверяет, что сервис генерирует уникальный id  
- **Автотест:** `test_create_ad_unique_id`

---

## 2. Получение объявления по id
**Endpoint:** `GET /ads/{id}`

**ATC-004 — Получение объявления по существующему id**

- **Тип:** Позитивный  
- **Покрытие:** существующий `id`  
- **Ожидаемый результат:** `200 OK`, данные объявления возвращены  
- **Комментарий:** проверяются все ключевые поля ответа (`id`, `name`, `price`, `statistics`)  
- **Автотест:** `test_get_ad_existing_id`

**ATC-005 — Получение объявления по невалидному id**
- **Тип:** Негативный  
- **Покрытие:**  
  - несуществующий `id`  
  - пустой `id`  
  - строковое значение вместо числового  
- **Ожидаемый результат:** `404 Not Found` или `400 Bad Request`  
- **Комментарий:** параметризация автотеста ATC-004  
- **Автотест:** `test_get_ad_invalid_id`

---

## 3. Получение объявлений по sellerId
**Endpoint:** `GET /ads?sellerId=...`

**ATC-006 — Получение списка объявлений продавца с объявлениями**
- **Тип:** Позитивный  
- **Покрытие:** продавец с существующими объявлениями  
- **Ожидаемый результат:** список объявлений  
- **Автотест:** `test_get_ads_existing_seller`

**ATC-007 — Получение списка объявлений продавца без объявлений**
- **Тип:** Негативный  
- **Покрытие:** продавец без объявлений  
- **Ожидаемый результат:** пустой список  
- **Комментарий:** параметризация автотеста ATC-006  
- **Автотест:** `test_get_ads_no_ads`

**ATC-008 — Получение объявлений с невалидным sellerId**
- **Тип:** Негативный  
- **Покрытие:**  
  - пустой `sellerId`  
  - несуществующий `sellerId`  
- **Ожидаемый результат:** `400 Bad Request`  
- **Автотест:** `test_get_ads_invalid_seller`

## 4. Проверка структуры и формата ответов

**ATC-009 — Проверка Content-Type ответа**
- **Тип:** Позитивный  
- **Методы:** `GET`, `POST`  
- **Покрытие:** `Content-Type = application/json`  
- **Автотест:** `test_response_headers`

**ATC-010 — Проверка обязательных полей в JSON-ответе**
- **Тип:** Позитивный  
- **Методы:** `GET`, `POST`  
- **Покрытие:** наличие всех обязательных полей  
- **Автотест:** `test_response_body_fields`
