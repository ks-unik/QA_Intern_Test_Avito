# Тест-кейсы для микросервиса объявлений

| ID | Категория сценария | Подтип сценария | Название сценария | Эндпоинт | Метод | Покрытие | Ожидаемый результат | Комментарий | Автотест |

## 1. Создание объявления (POST /ads)

### Позитивные сценарии
| ATC-001 | Создание объявления | Позитивный | Создание объявления с валидными данными | /ads | POST | Валидные обязательные поля | 200 OK | Отдельный автотест | test_create_ad_valid_data |

### Негативные сценарии
| ATC-002 | Создание объявления | Негативный | Создание объявления с невалидными данными | /ads | POST | Пустой id, пустой title, короткий/длинный title | 400 Bad Request | Параметризованный тест | test_create_ad_invalid_data |
| ATC-003 | Создание объявления | Негативный | Создание объявления с уже существующим id | /ads | POST | Проверка уникальности id | Ошибка создания (409 / 400) | Отдельный автотест | test_create_ad_duplicate_id |

## 2. Получение объявления по id (GET /ads/{id})

### Позитивные сценарии
| ATC-004 | Получение по id | Позитивный | Получение объявления по существующему id | /ads/{id} | GET | Существующий id | 200 OK | Отдельный автотест | test_get_ad_existing_id |

### Негативные сценарии
| ATC-005 | Получение по id | Негативный | Получение объявления с невалидным id | /ads/{id} | GET | Несуществующий, пустой, строковый id | 404 / 400 | Параметризованный тест | test_get_ad_invalid_id |

## 3. Получение всех объявлений по sellerId (GET /ads?sellerId=…)

### Позитивные сценарии
| ATC-006 | Получение по sellerId | Позитивный | Получение списка объявлений для продавца с объявлениями | /ads?sellerId=… | GET | Существующие объявления | Список объявлений | Отдельный автотест | test_get_ads_existing_seller |

### Негативные сценарии
| ATC-007 | Получение по sellerId | Негативный | Получение списка объявлений для продавца без объявлений | /ads?sellerId=… | GET | Проверка пустого списка | Пустой список | Отдельный автотест | test_get_ads_empty_seller |
| ATC-008 | Получение по sellerId | Негативный | Получение объявлений с невалидным sellerId | /ads?sellerId=… | GET | Несуществующий / пустой sellerId | 400 Bad Request | Параметризованный тест | test_get_ads_invalid_seller |

## 4. Проверка ответа

### Позитивные сценарии
| ATC-009 | Проверка ответа | Позитивный | Проверка Content-Type и структуры ответа | Любой | GET / POST | Content-Type, структура JSON | application/json | Отдельный автотест | test_response_headers |
| ATC-010 | Проверка ответа | Позитивный | Проверка обязательных полей в JSON-ответе | Любой | GET / POST | Наличие всех обязательных полей | Поля присутствуют | Отдельный автотест | test_response_body_fields |

## 5. Граничные сценарии
| ATC-011 | Граничные сценарии | Граничный | Обновление объявления с несколькими полями одновременно | /ads/{id} | PUT | Одновременное обновление нескольких полей | 200 OK | Отдельный автотест | test_update_ad_multiple_fields |
| ATC-012 | Граничные сценарии | Граничный | Удаление уже удалённого объявления | /ads/{id} | DELETE | Повторное удаление | Ошибка / 404 | Отдельный автотест | test_delete_already_deleted_ad |

## 6. Статистика (GET /stats/{itemId})

### Позитивные сценарии
| ATC-013 | Статистика | Позитивный | Получение статистики по существующему itemId | /stats/{itemId} | GET | Существующие данные | 200 OK, корректная статистика | Отдельный автотест | test_get_stats_existing_item |

### Негативные сценарии
| ATC-014 | Статистика | Негативный | Получение/обновление статистики для несуществующего itemId | /stats/{itemId} | GET / PUT | Несуществующий itemId | 404 / ошибка | Параметризованный тест | test_stats_invalid_item |

### Логическая проверка / консистентность
| ATC-015 | Статистика | Логическая проверка | Проверка консистентности статистики после создания/удаления объявлений | /stats/{itemId} | GET | Создание/удаление объявлений → проверка статистики | Сумма просмотров/продаж корректна | Отдельный автотест | test_stats_consistency |

### Проверка типов данных
| ATC-016 | Статистика | Проверка типов | Проверка типов данных в статистике | /stats/{itemId} | GET | Числа: integer/float, строки: string | Типы данных корректны | Отдельный автотест | test_stats_data_types |
