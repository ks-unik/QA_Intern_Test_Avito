# Тест-кейсы для микросервиса объявлений

## 1. Создание объявления (POST /ads)

### Позитивные сценарии
**ATC-001**  
**Название:** Создание объявления с валидными данными  
**Эндпоинт:** /ads  
**Метод:** POST  
**Покрытие:** Валидные обязательные поля  
**Ожидаемый результат:** 200 OK  
**Комментарий:** Отдельный автотест  
**Автотест:** test_create_ad_valid_data

### Негативные сценарии
**ATC-002**  
**Название:** Создание объявления с невалидными данными  
**Эндпоинт:** /ads  
**Метод:** POST  
**Покрытие:** Пустой id, пустой title, короткий/длинный title  
**Ожидаемый результат:** 400 Bad Request  
**Комментарий:** Параметризованный тест  
**Автотест:** test_create_ad_invalid_data

**ATC-003**  
**Название:** Создание объявления с уже существующим id  
**Эндпоинт:** /ads  
**Метод:** POST  
**Покрытие:** Проверка уникальности id  
**Ожидаемый результат:** Ошибка создания (409 / 400)  
**Комментарий:** Отдельный автотест  
**Автотест:** test_create_ad_duplicate_id

## 2. Получение объявления по id (GET /ads/{id})

### Позитивные сценарии
**ATC-004**  
**Название:** Получение объявления по существующему id  
**Эндпоинт:** /ads/{id}  
**Метод:** GET  
**Покрытие:** Существующий id  
**Ожидаемый результат:** 200 OK  
**Комментарий:** Отдельный автотест  
**Автотест:** test_get_ad_existing_id

### Негативные сценарии
**ATC-005**  
**Название:** Получение объявления с невалидным id  
**Эндпоинт:** /ads/{id}  
**Метод:** GET  
**Покрытие:** Несуществующий, пустой, строковый id  
**Ожидаемый результат:** 404 / 400  
**Комментарий:** Параметризованный тест  
**Автотест:** test_get_ad_invalid_id

## 3. Получение всех объявлений по sellerId (GET /ads?sellerId=…)

### Позитивные сценарии
**ATC-006**  
**Название:** Получение списка объявлений для продавца с объявлениями  
**Эндпоинт:** /ads?sellerId=…  
**Метод:** GET  
**Покрытие:** Существующие объявления  
**Ожидаемый результат:** Список объявлений  
**Комментарий:** Отдельный автотест  
**Автотест:** test_get_ads_existing_seller

### Негативные сценарии
**ATC-007**  
**Название:** Получение списка объявлений для продавца без объявлений  
**Эндпоинт:** /ads?sellerId=…  
**Метод:** GET  
**Покрытие:** Проверка пустого списка  
**Ожидаемый результат:** Пустой список  
**Комментарий:** Отдельный автотест  
**Автотест:** test_get_ads_empty_seller

**ATC-008**  
**Название:** Получение объявлений с невалидным sellerId  
**Эндпоинт:** /ads?sellerId=…  
**Метод:** GET  
**Покрытие:** Несуществующий / пустой sellerId  
**Ожидаемый результат:** 400 Bad Request  
**Комментарий:** Параметризованный тест  
**Автотест:** test_get_ads_invalid_seller
