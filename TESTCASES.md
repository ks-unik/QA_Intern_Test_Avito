# Тест-кейсы для микросервиса объявлений

**Общее количество тест-кейсов:** 16  
**Количество автотестов:** 10  

---

## 1. Создание объявления
**Endpoint:** `POST /ads`

### 1.1 Позитивные сценарии

**ATC-001 — Создание объявления с корректными данными**
- **Тип:** Позитивный  
- **Покрытие:** все обязательные поля заполнены валидными значениями  
- **Ожидаемый результат:** `200 OK`, объявление успешно создано  
- **Комментарий:** параметризованный автотест, проверяет несколько вариантов валидных данных  
- **Автотест:** `test_create_ad_valid_data`

---

### 1.2 Негативные сценарии

**ATC-002 — Создание объявления с невалидными значениями полей**
- **Тип:** Негативный  
- **Покрытие:**  
  - пустой `id`  
  - пустой `title`  
  - `title` меньше или больше допустимой длины  
- **Ожидаемый результат:** `400 Bad Request`  
- **Комментарий:** параметризованный автотест  
- **Автотест:** `test_create_ad_invalid_data`

**ATC-003 — Создание объявления с уже существующим id**
- **Тип:** Негативный  
- **Покрытие:** проверка уникальности `id`  
- **Ожидаемый результат:** `409 Conflict` или `400 Bad Request`  
- **Комментарий:** отдельный автотест  
- **Автотест:** `test_create_ad_duplicate_id`

---

## 2. Получение объявления по id
**Endpoint:** `GET /ads/{id}`

**ATC-004 — Получение объявления по существующему id**
- **Тип:** Позитивный  
- **Покрытие:** существующий `id`  
- **Ожидаемый результат:** `200 OK`, данные объявления возвращены  
- **Автотест:** `test_get_ad_existing_id`

**ATC-005 — Получение объявления по невалидному id**
- **Тип:** Негативный  
- **Покрытие:**  
  - несуществующий `id`  
  - пустой `id`  
  - строковое значение вместо числового  
- **Ожидаемый результат:** `404 Not Found` или `400 Bad Request`  
- **Комментарий:** параметризация автотеста ATC-004  
- **Автотест:** `test_get_ad_existing_id`

---

## 3. Получение объявлений по sellerId
**Endpoint:** `GET /ads?sellerId=...`

- **Ожидаемый результат:** список объявлений

**ATC-007 — Получение списка объявлений продавца без объявлений**
- **Тип:** Негативный  
- **Покрытие:** продавец без объявлений  
- **Ожидаемый результат:** пустой список  
- **Комментарий:** параметризация автотеста ATC-006  
- **Автотест:** `test_get_ads_existing_seller`

**ATC-008 — Получение объявлений с невалидным sellerId**
- **Тип:** Негативный  
- **Покрытие:**  
  - пустой `sellerId`  
  - несуществующий `sellerId`  
- **Ожидаемый результат:** `400 Bad Request`  
- **Автотест:** `test_get_ads_existing_seller`

## 5. Граничные сценарии

**ATC-011 — Обновление объявления с изменением нескольких полей**
- **Тип:** Граничный  
- **Endpoint:** `PUT /ads/{id}`  
- **Покрытие:** одновременное обновление нескольких атрибутов  
- **Ожидаемый результат:** `200 OK`  
- **Автотест:** `test_boundary_update_delete`

**ATC-012 — Удаление уже удалённого объявления**
- **Тип:** Граничный  
- **Endpoint:** `DELETE /ads/{id}`  
- **Покрытие:** повторный DELETE-запрос  
- **Ожидаемый результат:** ошибка или `404 Not Found`  
- **Автотест:** `test_boundary_update_delete`

## 6. Статистика
**Endpoint:** `GET /stats/{itemId}`

**ATC-013 — Получение статистики для существующего itemId**
- **Тип:** Позитивный  
- **Покрытие:** существующие данные  
- **Ожидаемый результат:** `200 OK`, корректная статистика  
- **Автотест:** `test_stats`

**ATC-014 — Получение статистики для несуществующего itemId**
- **Тип:** Негативный  
- **Методы:** `GET`, `PUT`  
- **Ожидаемый результат:** `404 Not Found` или ошибка  
- **Автотест:** `test_stats`

**ATC-015 — Проверка консистентности статистики**
- **Тип:** Логическая проверка  
- **Покрытие:** создание и удаление объявлений с последующей проверкой статистики  
- **Ожидаемый результат:** статистика обновляется корректно  
- **Автотест:** `test_stats`

**ATC-016 — Проверка типов данных в статистике**
- **Тип:** Валидация данных  
- **Покрытие:** соответствие типов данных контракту API  
- **Ожидаемый результат:** типы данных корректны  
- **Автотест:** `test_stats`
